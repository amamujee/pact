About

Pact turns your team's casual Slack promises into accountable, tracked commitments. When someone says "I'll get that to you Friday," Pact makes sure Friday actually happens.

Create a pact with one command — /pact, a 🤝 emoji reaction, or right-click → "Create a pact" — and both parties get a confirmation instantly. From there, Pact handles the lifecycle automatically: reminders in the 24 hours before due date, overdue nudges, and a 🎉 when it's done.

No spreadsheets. No follow-up threads. No wondering if it happened.

Features

⚡
Multiple creation methods
/pact command, 🤝 emoji reaction, or right-click any message to create a pact. Works for DMs, channels, and threads.
🔔
Smart reminders
Both parties get a DM reminder 24 hours before the due date. No manual chasing required.
⏰
Overdue nudges
If a commitment goes past due, Pact nudges both people to reschedule or close it out.
✅
/done command
Close pacts with /done, the ✅ emoji, or a "done" reply in the thread. Fuzzy matching handles typos.
🏠
Home Tab dashboard
Active pacts, overdue items, streak count, and quick-create — all in one view inside Slack.
📋
Daily & weekly digests
Morning summary of everything open, due soon, or overdue. Configurable per user.
🔄
Recurring pacts
Set daily, weekly, or custom cadences. The next instance auto-creates when you close the current one.
🔥
Commitment streaks
Track your on-time completion rate. Milestones at 7, 30, and 100 consecutive days. Share your card.
📅
Reschedule proposals
Either party can propose a new date — the other accepts, declines, or counters.
🤖
AI commitment detection
AI spots casual commitments in channels and suggests creating a formal pact. Snooze per channel.
⚙️
Workflow Builder steps
Trigger pact creation from any Slack workflow automation — pipelines, standups, deployments.
🔗
Tracker sync
Sync completed pacts to Linear, Notion, or Asana automatically.

Permissions

Scope Why we need it
commands Respond to /pact, /done, /pacts, and other slash commands entered by users.
chat:write Post pact creation confirmations, reminders, and completion celebrations in channels and DMs.
im:write Open a direct message with a user when they install the app for the first time (welcome DM).
im:read Read the content of DMs to identify emoji reactions (✅ / 🤝) that close or create pacts.
im:history Look back through DM history to find existing pacts when a user types /done.
users:read Look up user names and timezones to personalize reminder messages and digests.
reactions:read Detect 🤝 reactions on messages (pact creation) and ✅ reactions (completion) in channels and DMs.
channels:history Scan channel messages for pact creation via right-click "Create a pact" shortcut and AI commitment detection.
groups:history Same as channels — support for private Slack channels when Pact is used there.
mpim:history Support pact creation and tracking in multi-person DMs where commitments are made.

Additional Info

Works with

All Slack workspaces. Every feature is included for free.

Data handling

Pact stores pact text, due dates, user IDs, and Slack workspace IDs. Slack message content is read to detect emoji reactions and create pacts — it is not stored long-term beyond what's needed for pact tracking.

Install limit

One Pact installation per Slack workspace.

Version

Always up to date. Pact is deployed continuously via Polsia — you're always running the latest version.
